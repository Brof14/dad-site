# С днём рождения, папа!

Личная одностраничная видеооткрытка: один фильм, короткое обращение и никаких повторов кадров из видео в отдельной фотогалерее. Страница работает как обычный статический сайт, без сборщика, библиотек, аналитики и внешних шрифтовых сервисов.

## Посмотреть локально

Откройте `index.html` в браузере. Если браузер не воспроизводит локальный MP4, запустите статический сервер из папки проекта:

```powershell
python -m http.server 8000
```

Откройте `http://localhost:8000`.

## Поменять фильм или обложку

Замените `assets/papa-greeting.mp4` финальной версией фильма и сохраните имя файла. Обложка находится в `assets/poster.jpg`.

## Разместить на хостинге

Загрузите содержимое папки на любой статический хостинг. Относительные пути позволяют открыть сайт в подпапке или подключить домен. На GitHub Pages публикация настраивается в репозитории через **Settings → Pages**.

Шрифты лежат в `assets/fonts/`; текст лицензий — рядом с ними. Для аккуратной загрузки видео на медленном соединении у плеера отключена предварительная загрузка: файл начинает загружаться при запуске.
