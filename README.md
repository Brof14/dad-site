# С днём рождения, папа!

Локальная одностраничная открытка с одним главным видео. Никаких сборщиков, библиотек или внешних сервисов не требуется.

## Запуск

Откройте `index.html` в браузере. Если браузер ограничивает локальное видео, запустите простой статический сервер из этой папки:

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Замена видео

Замените `assets/papa-greeting.mp4` своей финальной версией, сохранив это имя. Для новой обложки замените `assets/poster.jpg`.

Страница использует относительные пути, поэтому её можно разместить на GitHub Pages или другом статическом хостинге и затем подключить домен.
